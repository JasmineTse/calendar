# 万年历 · 无广告离线版

一个**无广告、无内购、离线优先**的中文万年历（电子日历）Web 应用（PWA），可安装到手机桌面或电脑上使用。所有数据仅保存在本机，不上传任何内容。

## 功能

- **日历视图**：月 / 周 / 年三种视图；每个日期同时显示公历与农历；周末与法定节假日标红，调休补班日标"班"角标；假期倒计时；一键回到今天；跳转任意日期（1900–2100）
- **农历与传统信息**：农历日期、干支（年/月/日）、生肖、二十四节气、传统节日（春节/元宵/清明/端午/七夕/中秋/重阳/除夕等）与现代节日
- **法定节假日**：内置 2025、2026 年国务院办公厅公布的放假与调休安排，支持导入新数据更新；无数据年份仅周末标红，不会误标
- **每日宜忌（黄历）**：宜/忌、吉神宜趋、凶神宜忌、冲煞、胎神占方、彭祖百忌、喜神/财神方位（民俗内容，仅供参考）
- **日程与提醒**：标题/时间/备注/分类（工作·生活·纪念日·其他，颜色区分）/重复规则（每天·每周·每月·每年）；到点系统本地通知，可选提前量；节日与节气可"一键转为每年提醒"
- **每日一诗**：内置 300 首唐诗宋词名篇（含简明译文），每天按日期推荐一首，可"换一首"随机赏读；纯离线
- **十万个为什么**：10 个经典科普问答（天文、自然、动物、人体、生活），每天按日期随机展示一问，可"换一个"；纯离线
- **生理期记录（隐私优先）**：一键记录经期开始/结束；预测下次经期、排卵日、易孕期、安全期并在日历上用颜色区分（预测为虚线/浅色，与实际记录可区分）；周期长度与经期天数可调；近 6 个月周期趋势图；周期明显不规律时温和提示；数据仅存本机 + 应用锁（PIN）
- **其他**：深色模式跟随系统、数据导出/导入备份、 Service Worker 离线缓存、可安装为桌面/主屏幕应用

## 快速开始

本机已装 Python 3（无其他依赖）：

```bash
cd 万年历app
python server.py          # 默认 http://127.0.0.1:8642
python server.py 9000     # 自定义端口
```

浏览器打开 <http://127.0.0.1:8642> 即可。

- **电脑安装为应用**：Chrome/Edge 打开上面地址后，地址栏右侧会出现"安装"图标，安装后是独立窗口的桌面应用。
- **手机使用**：手机与电脑连同一 Wi-Fi，浏览器访问 `http://<电脑局域网IP>:8642`（可用 `ipconfig` 查看）。
- **手机安装到桌面**：Android Chrome 菜单 →"添加到主屏幕"；iOS Safari → 分享 →"添加到主屏幕"。

> 说明：`http://127.0.0.1` 属于安全上下文，离线缓存（Service Worker）与系统通知可完整使用；手机通过局域网 `http://IP` 访问时浏览器视为非安全上下文，此时**所有功能仍可正常使用**，仅离线缓存与系统通知受限。如需手机端完整体验，可将整个目录部署到任意 HTTPS 静态托管（如 GitHub Pages），或后续用 Capacitor 打包成 APK。

**想装到 iPhone 上长期使用？** 参见 [iPhone安装指南.md](iPhone安装指南.md)（免付费、免 Mac，5 分钟装好，含现成的 `万年历-iPhone部署包.zip`）。
**安卓手机？** 参见 [安卓安装指南.md](安卓安装指南.md)——同一部署包，Chrome"添加到主屏幕"即可，通知与离线能力更完整。

## 更新法定节假日数据

每年 11 月前后国务院办公厅公布次年安排后，三种更新方式任选：

1. **一键更新（推荐）**：设置页 →"🔄 更新假期"→ 自动联网获取**当年与次年**数据并合并。数据源依次尝试 timor.tech、[holiday-cn](https://github.com/NateScarlet/holiday-cn)（jsDelivr / GitHub 镜像），单源失败自动切换；次年安排尚未公布时会明确提示。仅此操作需要网络。
2. 手动导入：设置页 → 导入 JSON（格式见下，导入后覆盖内置，可随时"恢复内置数据"）。
3. 直接编辑 `data/holidays.json` 后重新部署。

格式示例：

```json
{
  "years": {
    "2027": {
      "holidays": [{ "name": "元旦", "days": ["2027-01-01", "2027-01-02", "2027-01-03"] }],
      "workdays": [{ "name": "元旦调休", "days": ["2027-01-09"] }]
    }
  }
}
```

## 技术选型

- **原生 JavaScript（ES Modules）+ 原生 CSS**，无构建步骤、无框架
- **农历/黄历**：[lunar-javascript](https://github.com/6tail/lunar-javascript) v1.7.7（已内置 `js/lib/lunar.js`，离线可用，覆盖 1900–2100 年），未自行实现农历算法
- **存储**：localStorage 单键 JSON（`wnl_data_v1`），设置页可导出/导入备份
- **提醒**：Notification API 本地通知，应用前台每 30 秒检查（安装为应用后更可靠）；不依赖任何推送服务
- **节假日**：JSON 数据文件 + 内存索引；"更新假期"功能仅在用户点击时联网，依次尝试 timor.tech 与 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn) 数据集（jsDelivr、GitHub 双镜像），8 秒超时自动切换下一源
- **图标**：内嵌 SVG + PNG，无外部资源

## 已知限制

- 浏览器通知需要本应用处于运行状态（浏览器标签页或安装后的应用）；完全关机状态下的推送需要服务端，与"离线、不采集数据"的定位冲突，故未实现
- iOS 对 Web 通知支持有限，生理期提醒在 iOS 上可能不弹系统通知（日历内标注不受影响）
- 黄历宜忌为民俗推算内容，仅供参考；生理期预测基于日历法，不作为医疗或避孕依据

## 隐私

无广告、无内购、无账号体系、无第三方统计 SDK；除加载应用自身文件外，**仅在点击"更新假期"时联网**获取节假日数据（可选功能，不点不联网）。日程与生理期数据仅存于本机浏览器，可随时导出备份或一键清空。
